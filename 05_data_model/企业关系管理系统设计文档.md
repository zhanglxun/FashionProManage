## 🎯 系统概述

### 业务背景
FashionProManage 是一个面向时尚行业的综合管理平台，支持企业间的复杂业务关系管理。系统需要支持多种企业类型（代理商、供应商、工厂、客户等）及其相互关系的建立和管理。

### 核心需求
- **多企业类型支持**：代理商、供应商、工厂、客户等多种角色
- **复杂关系管理**：企业间可以建立双向、多层次的业务关系
- **数据权限隔离**：每个企业只能看到和管理自己的关系网络
- **平台超级权限**：平台运营公司可以查看所有企业关系

### 设计原则
- **最小化必要性**：只保留核心功能，避免过度设计
- **数据一致性**：通过外键约束保证数据完整性
- **查询性能**：通过合理索引优化关系查询效率
- **扩展灵活性**：支持未来业务扩展需求

## 🔄 核心业务场景

### 场景1：客户创建供应商和工厂

#### 业务流程：
1. 客户A在系统中注册企业
2. A创建供应商B（录入基本信息和供应商扩展字段）
3. A创建工厂C（录入基本信息和工厂扩展字段）
4. A建立与B、C的业务关系

#### 数据实现：
```sql
-- 1. 创建企业A（代理商）
INSERT INTO o_enterprise (id, name, type, ...) VALUES (1001, '客户A公司', 2, ...);

-- 2. 创建供应商B
INSERT INTO o_enterprise (id, name, type, supplier_type, production_capacity, ...)
VALUES (1002, '供应商B公司', 3, 1, '月产10万米', ...);

-- 3. 创建工厂C
INSERT INTO o_enterprise (id, name, type, factory_type, production_capacity, ...)
VALUES (1003, '加工工厂C', 4, '1-加工,2-印花', '月加工8万米', ...);

-- 4. 建立关系：A -> B（供应关系）
INSERT INTO o_enterprise_relation (from_enterprise_id, to_enterprise_id, relation_type, business_type)
VALUES (1001, 1002, 2, 2);

-- 5. 建立关系：A -> C（供应关系）
INSERT INTO o_enterprise_relation (from_enterprise_id, to_enterprise_id, relation_type, business_type)
VALUES (1001, 1003, 2, 3);
```

### 场景2：供应商也成为客户，建立双向关系

#### 业务流程：
1. 供应商B在系统升级为综合供应商（type=5）
2. B建立与A的客户关系
3. B也发展了与工厂C的业务关系
4. 形成复杂的关系网络

#### 数据实现：
```sql

-- 2. B建立与A的客户关系
INSERT INTO o_enterprise_relation (from_enterprise_id, to_enterprise_id, relation_type, business_type)
VALUES (1002, 1001, 3, 6);

-- 3. B建立与C的供应关系
INSERT INTO o_enterprise_relation (from_enterprise_id, to_enterprise_id, relation_type, business_type)
VALUES (1002, 1003, 2, 3);
```

### 场景3：平台公司超级权限管理

#### 业务流程：
1. 平台公司通过代理商表注册（parent_id = 0）
2. 平台可以查看所有企业和关系
3. 普通企业只能看到自己的关系网络

#### 识别逻辑：
```sql
-- 识别平台公司
SELECT * FROM o_enterprise_agent WHERE parent_id = 0;

-- 平台公司查看所有关系
SELECT * FROM o_enterprise_relation;

-- 普通企业查看自己的关系
SELECT * FROM o_enterprise_relation
WHERE from_enterprise_id = @current_enterprise_id OR to_enterprise_id = @current_enterprise_id;
```

## 🛡️ 数据权限控制

### 权限控制原则

#### 1. 基础权限规则
- **企业自身数据**：企业只能查看和修改自己的基础信息
- **关系数据**：企业只能查看和管理自己创建或参与的关系
- **平台权限**：平台公司可以查看所有数据（通过代理商表识别）

#### 2. 数据范围隔离
每个企业登录时只能看到以下数据：
- 自己的基础信息
- 自己创建的关系记录（from_enterprise_id = 企业ID）
- 别人创建但涉及自己的关系记录（to_enterprise_id = 企业ID）
- 状态为正常的关系记录（status = 1）

### SQL权限查询实现

#### 1. 普通企业权限查询
```sql
-- 获取当前企业能看到的所有相关企业
WITH enterprise_network AS (
  -- 自己作为关系发起方的企业
  SELECT to_enterprise_id as related_id, relation_type, 'outgoing' as direction
  FROM o_enterprise_relation
  WHERE from_enterprise_id = @current_enterprise_id AND status = 1

  UNION ALL

  -- 自己作为关系接收方的企业
  SELECT from_enterprise_id as related_id, relation_type, 'incoming' as direction
  FROM o_enterprise_relation
  WHERE to_enterprise_id = @current_enterprise_id AND status = 1
)
SELECT DISTINCT
  e.*,
  en.relation_type,
  en.direction,
  r.description as relation_description
FROM enterprise_network en
JOIN o_enterprise e ON en.related_id = e.id
LEFT JOIN o_enterprise_relation r ON (
  (r.from_enterprise_id = @current_enterprise_id AND r.to_enterprise_id = e.id) OR
  (r.from_enterprise_id = e.id AND r.to_enterprise_id = @current_enterprise_id)
)
WHERE e.status = 1
ORDER BY e.name;
```

#### 2. 平台公司超级权限查询
```sql
-- 平台公司查看完整关系网络
SELECT
  r.*,
  from_e.name as from_enterprise_name,
  from_e.type as from_enterprise_type,
  to_e.name as to_enterprise_name,
  to_e.type as to_enterprise_type
FROM o_enterprise_relation r
JOIN o_enterprise from_e ON r.from_enterprise_id = from_e.id
JOIN o_enterprise to_e ON r.to_enterprise_id = to_e.id
WHERE r.status = 1
ORDER BY r.from_enterprise_id, r.to_enterprise_id;
```

#### 3. 权限控制函数（应用层使用）
```sql
-- 检查用户是否有权限查看特定关系
CREATE FUNCTION fn_can_access_relation(
  p_enterprise_id BIGINT,
  p_relation_id BIGINT
) RETURNS BOOLEAN
READS SQL DATA
DETERMINISTIC
BEGIN
  DECLARE v_is_platform BOOLEAN DEFAULT FALSE;
  DECLARE v_has_permission BOOLEAN DEFAULT FALSE;

  -- 检查是否为平台公司
  SELECT COUNT(*) > 0 INTO v_is_platform
  FROM o_enterprise_agent
  WHERE enterprise_id = p_enterprise_id AND parent_id = 0;

  IF v_is_platform THEN
    RETURN TRUE;
  END IF;

  -- 检查是否为关系参与方
  SELECT COUNT(*) > 0 INTO v_has_permission
  FROM o_enterprise_relation
  WHERE id = p_relation_id
    AND status = 1
    AND (from_enterprise_id = p_enterprise_id OR to_enterprise_id = p_enterprise_id);

  RETURN v_has_permission;
END;
```

### 关系管理权限

#### 1. 创建关系权限
```sql
-- 检查是否有权限创建关系（应用层调用）
INSERT INTO o_enterprise_relation (from_enterprise_id, to_enterprise_id, relation_type, ...)
SELECT @current_enterprise_id, @target_enterprise_id, @relation_type, ...
WHERE EXISTS (
  SELECT 1 FROM o_enterprise
  WHERE id = @target_enterprise_id AND status = 1
) AND @current_enterprise_id <> @target_enterprise_id;  -- 防止自关联
```

#### 2. 修改关系权限
```sql
-- 只能修改自己创建的关系
UPDATE o_enterprise_relation
SET relation_type = @new_type, description = @description
WHERE id = @relation_id
  AND from_enterprise_id = @current_enterprise_id
  AND status = 1;
```

#### 3. 删除关系权限
```sql
-- 只能删除自己创建的关系
UPDATE o_enterprise_relation
SET status = 3  -- 终止状态
WHERE id = @relation_id
  AND from_enterprise_id = @current_enterprise_id;
```

## ⚡ SQL实现方案

### 基础查询模板

#### 1. 企业关系网络查询
```sql
-- 查询指定企业的完整关系网络
DELIMITER //
CREATE PROCEDURE sp_get_enterprise_network(
  IN p_enterprise_id BIGINT,
  IN p_max_depth INT DEFAULT 3
)
BEGIN
  WITH RECURSIVE relation_network AS (
    -- 基础层：直接关系
    SELECT
      from_enterprise_id,
      to_enterprise_id,
      relation_type,
      1 as level,
      CONCAT(from_enterprise_id, '->', to_enterprise_id) as path
    FROM o_enterprise_relation
    WHERE (from_enterprise_id = p_enterprise_id OR to_enterprise_id = p_enterprise_id)
      AND status = 1

    UNION ALL

    -- 递归层：通过直接关系扩展
    SELECT
      CASE
        WHEN rn.from_enterprise_id = p_enterprise_id THEN r.from_enterprise_id
        ELSE r.to_enterprise_id
      END as from_enterprise_id,
      CASE
        WHEN rn.to_enterprise_id = p_enterprise_id THEN r.to_enterprise_id
        ELSE r.from_enterprise_id
      END as to_enterprise_id,
      r.relation_type,
      rn.level + 1,
      CONCAT(rn.path, '->',
        CASE
          WHEN rn.from_enterprise_id = p_enterprise_id THEN r.to_enterprise_id
          ELSE r.from_enterprise_id
        END
      ) as path
    FROM relation_network rn
    JOIN o_enterprise_relation r ON (
      (r.from_enterprise_id = rn.to_enterprise_id OR r.to_enterprise_id = rn.to_enterprise_id)
      AND r.status = 1
      AND FIND_IN_SET(
        CASE
          WHEN rn.from_enterprise_id = p_enterprise_id THEN r.to_enterprise_id
          ELSE r.from_enterprise_id
        END,
        REPLACE(rn.path, CONCAT(p_enterprise_id, '->'), '')
      ) = 0  -- 防止循环
    )
    WHERE rn.level < p_max_depth
  )
  SELECT
    rn.*,
    from_e.name as from_enterprise_name,
    from_e.type as from_enterprise_type,
    to_e.name as to_enterprise_name,
    to_e.type as to_enterprise_type,
    r.description
  FROM relation_network rn
  JOIN o_enterprise from_e ON rn.from_enterprise_id = from_e.id
  JOIN o_enterprise to_e ON rn.to_enterprise_id = to_e.id
  LEFT JOIN o_enterprise_relation r ON (
    r.from_enterprise_id = rn.from_enterprise_id
    AND r.to_enterprise_id = rn.to_enterprise_id
  )
  ORDER BY rn.level, from_e.name, to_e.name;
END //
DELIMITER ;
```

#### 2. 关系统计分析
```sql
-- 企业关系统计查询
SELECT
  e.id as enterprise_id,
  e.name as enterprise_name,
  e.type as enterprise_type,

  -- 关系统计
  COUNT(DISTINCT CASE WHEN r.from_enterprise_id = e.id THEN r.to_enterprise_id
                     WHEN r.to_enterprise_id = e.id THEN r.from_enterprise_id END) as total_connections,

  -- 按关系类型统计
  COUNT(DISTINCT CASE WHEN r.relation_type = 1 THEN
                     CASE WHEN r.from_enterprise_id = e.id THEN r.to_enterprise_id
                          WHEN r.to_enterprise_id = e.id THEN r.from_enterprise_id END END) as agent_connections,
  COUNT(DISTINCT CASE WHEN r.relation_type = 2 THEN
                     CASE WHEN r.from_enterprise_id = e.id THEN r.to_enterprise_id
                          WHEN r.to_enterprise_id = e.id THEN r.from_enterprise_id END END) as supplier_connections,
  COUNT(DISTINCT CASE WHEN r.relation_type = 3 THEN
                     CASE WHEN r.from_enterprise_id = e.id THEN r.to_enterprise_id
                          WHEN r.to_enterprise_id = e.id THEN r.from_enterprise_id END END) as customer_connections,

  -- 出度和入度统计
  COUNT(DISTINCT r.to_enterprise_id) as outbound_connections,
  COUNT(DISTINCT r.from_enterprise_id) as inbound_connections,

  -- 最后更新时间
  MAX(GREATEST(r.create_time, r.modify_time)) as last_activity
FROM o_enterprise e
LEFT JOIN o_enterprise_relation r ON (
  (r.from_enterprise_id = e.id OR r.to_enterprise_id = e.id)
  AND r.status = 1
)
WHERE e.status = 1
GROUP BY e.id, e.name, e.type
ORDER BY total_connections DESC;
```

#### 3. 关系路径查找
```sql
-- 查找两个企业之间的最短关系路径
DELIMITER //
CREATE PROCEDURE sp_find_shortest_path(
  IN p_from_enterprise_id BIGINT,
  IN p_to_enterprise_id BIGINT,
  IN p_max_depth INT DEFAULT 5
)
BEGIN
  WITH RECURSIVE shortest_path AS (
    -- 基础层：从起始企业的直接关系
    SELECT
      from_enterprise_id,
      to_enterprise_id,
      relation_type,
      1 as depth,
      CAST(from_enterprise_id AS CHAR(1000)) as path,
      from_enterprise_id as start_id
    FROM o_enterprise_relation
    WHERE from_enterprise_id = p_from_enterprise_id AND status = 1

    UNION ALL

    -- 递归查找
    SELECT
      r.from_enterprise_id,
      r.to_enterprise_id,
      r.relation_type,
      sp.depth + 1,
      CONCAT(sp.path, '->', r.to_enterprise_id) as path,
      sp.start_id
    FROM shortest_path sp
    JOIN o_enterprise_relation r ON (
      sp.to_enterprise_id = r.from_enterprise_id
      AND r.status = 1
      AND FIND_IN_SET(r.to_enterprise_id, REPLACE(sp.path, '->', ',')) = 0
    )
    WHERE sp.depth < p_max_depth
  )
  SELECT
    sp.*,
    from_e.name as from_enterprise_name,
    to_e.name as to_enterprise_name,
    r.description
  FROM shortest_path sp
  JOIN o_enterprise from_e ON sp.from_enterprise_id = from_e.id
  JOIN o_enterprise to_e ON sp.to_enterprise_id = to_e.id
  LEFT JOIN o_enterprise_relation r ON (
    r.from_enterprise_id = sp.from_enterprise_id
    AND r.to_enterprise_id = sp.to_enterprise_id
  )
  WHERE sp.to_enterprise_id = p_to_enterprise_id
  ORDER BY sp.depth
  LIMIT 1;
END //
DELIMITER ;
```
